# Commity

AI-powered commit message generator for VS Code.

## Features

- Generate commit messages with a single click from the Source Control view
- Icon appears in the Git toolbar when you have a Git repository open

## Development

1. Install dependencies: `npm install`
2. Compile: `npm run compile`
3. Press F5 to open a new VS Code window with the extension loaded
4. Open a Git repository and click the sparkle icon in the Source Control view
